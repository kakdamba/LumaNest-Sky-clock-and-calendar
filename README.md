# 🌻 LumaNest (Version V.2)
*Made with 🍊 and 🌻 — Built by KAKDAMBA*

LumaNest is an offline-first companion application crafted for players of **Sky: Children of the Light**.

---

## ✨ Features
- 🕰️ **Dynamic Event Clock & Timers**: Track Geyser, Grandma, Turtle, Shards, and Traveling Spirits in real time with local countdowns.
- 🌍 **Multi-Timezone Companion & Friends**: Compare event schedules with your friends across the world without timezone headaches.
- 🎨 **Cozy Night Sky UI**: Dark sky aesthetic crafted with Jetpack Compose and Material 3.
- 📅 **Interactive Calendar**: Plan and filter upcoming recurring events.
- 📱 **Home Screen Widget**: Glanceable next-event countdown directly on your Android launcher.
- 🔒 **Offline-First & Privacy Conscious**: 100% of your friend names and preferences stay safely on your device.

---

## 🛠️ Tech Stack & Architecture
- **Language**: Kotlin 2.0+
- **UI Toolkit**: Jetpack Compose & Material 3
- **Local Database**: Room DB (SQLite)
- **Time Engine**: `java.time` (ThreeTen / JSR-310) with custom cyclical Sky event algorithms
- **Widgets**: Jetpack Glance (AppWidget)
- **Minimum SDK**: Android 8.0 (API 26)
- **Target SDK**: Android 15 (API 35)

---

## 🚀 Building & Running
1. Clone the repository:
   ```bash
   git clone <YOUR_GITHUB_REPO_URL>
   ```
2. Open the project in **Android Studio** (Ladybug or newer recommended).
3. Connect an Android device or start an emulator running Android 8.0+.
4. Run:
   ```bash
   ./gradlew assembleDebug
   ```
